# 使用说明

## 第一次（大约 3 分钟）
1. 把下载的 zip 双击解压，得到“猫家具设计包”文件夹，放在你习惯的位置，比如“文稿”。
2. 打开 Codex，用你的 ChatGPT 账号登录。
3. 在 Codex 里选择“打开文件夹”（或新建项目），选中“猫家具设计包”。
4. 随便说一句话，例如“你好”。第一次打开时，助手会先在浏览器里放流程演示，再带你开始。

## 每次设计
- 说一句“我想做一款新产品”，跟着助手走，一共 7 步：定位 → 风格 → 白模 → 造型与配色 → 出图 → 修改 → 设计卡。
- 想挑白模，可以自己翻 `项目文件/目录_*.jpg`，看中哪个直接告诉助手编号就行，不用拖图。
- 想回头改，说“回到第 3 步”。想再看演示，说“看演示”。
- 做好的效果图和设计卡会存在 `作品/方案名/`，把这个文件夹发给工程师就行。
