# 猫家具设计包

👉 **打开这个网页开始：https://chihaku1230-ship-it.github.io/cat-furniture-design-kit/**

网页里有下载按钮、设置说明，还有两次完整的设计过程演示（卵石猫爬架、咕噜怪猫窝）。不需要注册 GitHub。

用法：下载 zip 解压，在 Codex 里打开 `猫家具设计包` 文件夹，随便说一句话。第一次打开时助手会先放流程演示。

- `猫家具设计包/`：下载解压后得到的文件夹
  - `AGENTS.md`：设计助手的指令（Codex 自动读取）
  - `先打开我·流程演示.html`：流程演示
  - `使用说明.md`：怎么开始
  - `项目文件/`：设计流程手册、模板目录、目录图
  - `模板/`：296 个白模和分区图（猫爬架 160、猫窝 80、抓板 56）
  - `示例/`：演示里的效果图和设计卡
  - `作品/`：设计师的方案会存在这里
